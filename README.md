| 類別                              | 新增或改進內容                                                                            | 說明                                      |
| ------------------------------- | ---------------------------------------------------------------------------------- | --------------------------------------- |
|  **功能主題轉變**                   |  從「一般聊天」變成「AI 旅遊導遊」                                                               | 有旅遊條件設定、自動行程規劃邏輯。                       |
|  **系統人格 System Prompt**      |  `systemPersona` 描述：「你是專業、貼心且務實的 AI 導遊…」                                          | 讓回覆更貼近旅遊場景，而非單純聊天。                      |
|  **旅遊條件設定**                   |  城市（city）、天數（days）、預算（budgetMin/Max）、興趣（interests）、親子（withKids）、雨天備案（rainPlan）等狀態 | 使用者可以客製化旅遊需求。                           |
|  **多語支援**                     |  語言選擇下拉選單：繁中／English／日本語                                                          | AI 回答會根據語言改變。                           |
|  **親子與天氣選項**         |  Checkbox：「親子友善」「雨天備案」                                                            | 增加更多旅遊情境。                               |
|  **沉浸模式 (immersive)**         |  按鈕「進入旅遊指南」切換模式                                                                   | 切換成純對話介面，自動觸發行程生成。                      |
|  **興趣標籤選擇**                  |  可點擊的 chip 按鈕（在地小吃、美食、文化景點…）                                                      | 點擊即選擇興趣，動態切換顏色。                         |
|  **行程自動生成邏輯**                 |  `useEffect` 監控 immersive 狀態，自動呼叫 `sendMessage()` 規劃旅程                            | 按下「進入旅遊指南」自動產生 AI 行程。                   |
|  **使用舊 SDK 實現多輪對話**           |  使用 `GoogleGenerativeAI` 舊 SDK                                                    | `AItest2` 改用新版 `@google/genai`。這版保留舊用法。 |
|  **更完整的對話歷史處理**              |  將 system context、使用者輸入、AI 回覆都納入歷史                                                | 確保 AI 回答能保持上下文一致。                       |
|  **Markdown-like rendering** |  自製 `renderMarkdownLike()`                                                        | 分行顯示文字內容並縮放呈現。                          |
|  **更精緻的 UI 風格**               |  有卡片、陰影、背景漸層、圓角、分段設計                                                              | 以「旅遊導覽」為主題配色（米色／咖啡色調）。                  |
|  **記住 API Key**               |  與 `AItest2` 相同，但整合在表單中、提示更明確                                                     | 同樣使用 localStorage，但更貼近 UX。              |
